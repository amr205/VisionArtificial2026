// Python · OpenCV Template Matching

import cv2
import numpy as np

# Cargar imagen fuente y template
img = cv2.imread('imagen.jpg')
template = cv2.imread('template.jpg')

# Convertir a escala de grises
img_gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
tmpl_gray = cv2.cvtColor(template, cv2.COLOR_BGR2GRAY)
h, w = tmpl_gray.shape

# Aplicar template matching
result = cv2.matchTemplate(
    img_gray, tmpl_gray,
    cv2.TM_CCOEFF_NORMED   # método
)

# Encontrar la posición de máxima similitud
_, max_val, _, max_loc = cv2.minMaxLoc(result)

# Dibujar bounding box
top_left = max_loc
bottom_right = (top_left[0] + w, top_left[1] + h)
cv2.rectangle(img, top_left, bottom_right,
             (0,255,0), 2)

# Multi-scale: resize template para robustez
for scale in np.linspace(0.5, 1.5, 20):
    resized = cv2.resize(tmpl_gray,
        None, fx=scale, fy=scale)
    res = cv2.matchTemplate(
        img_gray, resized,
        cv2.TM_CCOEFF_NORMED)

¿Cuándo usarlo?
Template Matching es ideal cuando el objeto a detectar es rígido, tiene apariencia constante y el fondo es relativamente controlado. Es extremadamente rápido y no necesita datos etiquetados. Su mayor limitación es la poca robustez ante cambios de iluminación, rotación o deformación. Se usa en automatización de pruebas de UI, inspección de calidad industrial y localización de marcadores fiduciales.

// Python · OpenCV Feature Matching (SIFT + FLANN)

import cv2
import numpy as np

img1 = cv2.imread('objeto.jpg', 0)
img2 = cv2.imread('escena.jpg', 0)

# Inicializar detector SIFT
sift = cv2.SIFT_create()

# Detectar y describir keypoints
kp1, des1 = sift.detectAndCompute(img1, None)
kp2, des2 = sift.detectAndCompute(img2, None)

# FLANN matcher (más rápido que BruteForce)
index_params = dict(algorithm=1, trees=5)
search_params = dict(checks=50)
flann = cv2.FlannBasedMatcher.create()
matches = flann.knnMatch(des1, des2, k=2)

# Ratio test de Lowe
good = [m for m, n in matches
        if m.distance < 0.75 * n.distance]

# Homografía + localización con RANSAC
if len(good) > 10:
    src_pts = np.float32(
        [kp1[m.queryIdx].pt for m in good]
    ).reshape(-1,1,2)
    dst_pts = np.float32(
        [kp2[m.trainIdx].pt for m in good]
    ).reshape(-1,1,2)
    M, mask = cv2.findHomography(
        src_pts, dst_pts, cv2.RANSAC, 5.0)

# ORB (libre de patente, más rápido)
orb = cv2.ORB_create(nfeatures=500)
kp, des = orb.detectAndCompute(img1, None)
bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)

¿Por qué Feature Matching sigue vigente?
A diferencia del template matching, estos métodos son invariantes a escala, rotación e iluminación. SIFT sigue siendo referencia en tareas de localización visual (SLAM, AR). Para aplicaciones en tiempo real, ORB y AKAZE ofrecen descriptores binarios que se comparan con distancia Hamming (muy rápida en CPU). RANSAC filtra outliers robustamente para estimar transformaciones geométricas.

// Arquitectura Siamese · Dos ramas · Correlación cruzada

// Python · SiamFC-style con PyTorch

import torch
import torch.nn as nn
import torch.nn.functional as F

class SiameseTracker(nn.Module):
    def __init__(self):
        super().__init__()
        # Backbone compartido (pesos iguales)
        self.backbone = nn.Sequential(
            nn.Conv2d(3,96,11,stride=2),
            nn.ReLU(),
            nn.MaxPool2d(3,stride=2),
            nn.Conv2d(96,256,5),
            nn.ReLU(),
        )

    def forward(self, z, x):
        # z: template 127×127, x: búsqueda 255×255
        z_feat = self.backbone(z)  # [B,256,6,6]
        x_feat = self.backbone(x)  # [B,256,22,22]

        # Correlación cruzada
        B = z_feat.size(0)
        score_map = F.conv2d(
            x_feat.view(1, -1, *x_feat.shape[2:]),
            z_feat.view(-1, *z_feat.shape[1:]),
            groups=B
        )
        return score_map

¿Por qué Siamese Networks para tracking?
Las redes Siamese aprenden una función de similitud entre el template inicial (objeto a seguir) y regiones de frames sucesivos. Al compartir pesos entre ambas ramas, se garantiza que ambas representaciones estén en el mismo espacio de características. La correlación cruzada actúa como un filtro aprendido. SiamRPN agrega regresión de bounding box y clasificación objeto/fondo, mientras SiamRPN++ usa ResNet y correlación depth-wise para mayor precisión.

Pionero

// 2015
Fast R-CNN
RoI Pooling
Pasa la imagen entera por la CNN una sola vez para obtener un feature map. Luego proyecta las propuestas de región (aún de Selective Search) al feature map usando RoI Pooling, extrayendo un vector de tamaño fijo por región. Clasifica y regresa la caja en un solo paso. 25× más rápido que R-CNN.
from torchvision.ops import roi_pool, roi_align

# feature_map: [B, C, H, W] — imagen completa
# boxes: [[x1,y1,x2,y2], ...] propuestas de región
pooled = roi_align(
    feature_map, boxes,
    output_size=(7,7),
    spatial_scale=1/32
)  # → [N, C, 7, 7]
// 2015
Faster R-CNN
End-to-End
Reemplaza Selective Search con una Region Proposal Network (RPN) que corre sobre el mismo feature map compartido. RPN predice objectness score y coordenadas de anclas. Comparte cómputo entre propuesta y detección, logrando ~5 FPS en GPU con alta precisión. Backbone típico: VGG16 o ResNet-50/101.

// 2017
FPN · Feature Pyramid Network
Multi-Escala
Construye una pirámide de features combinando el camino descendente (semánticamente rico, baja resolución) con el ascendente (alta resolución, menos semántico) mediante lateral connections de 1×1 conv. Detecta objetos en diferentes niveles de la pirámide según su tamaño. Mejora enormemente la detección de objetos pequeños.
// 2017
Mask R-CNN
Segmentación
Extiende Faster R-CNN añadiendo una tercera cabeza paralela que predice una máscara binaria de segmentación por cada RoI. Usa RoI Align (en lugar de RoI Pooling) para alineación sub-pixel precisa. Permite detección de instancias y es base de muchos frameworks actuales como Detectron2.

binary = (masks > 0.5).squeeze(1)

SSD · Single Shot MultiBox Detector
Multi-Scale
Predice en múltiples feature maps de diferente resolución (38×38, 19×19, 10×10, 5×5, 3×3, 1×1) usando anclas de diferentes aspect ratios. Backbone VGG16 con capas extras. Elimina la necesidad de upsampling. Excelente balance velocidad/precisión (~59 FPS, mAP 74.3 en VOC).
// 2017
RetinaNet · Focal Loss
Focal Loss
Identifica el problema de desbalance extremo foreground/background en detectores densos (1:1000). Introduce Focal Loss FL(p) = −(1−p)^γ · log(p) que reduce el peso de ejemplos fáciles (background) para enfocarse en casos difíciles. Usa FPN + ResNet. Iguala la precisión de Faster R-CNN manteniendo velocidad de single-stage.
import torch
import torch.nn.functional as F

def focal_loss(pred, target, gamma=2.0, alpha=0.25):
    bce = F.binary_cross_entropy_with_logits(
        pred, target, reduction='none')
    p_t = torch.exp(-bce)
    focal = alpha * (1 - p_t)**gamma * bce
    return focal.mean()

Single-Stage vs Two-Stage:
Los detectores single-stage tratan la detección como un problema de regresión densa directa, sin etapa de propuestas. Esto los hace significativamente más rápidos pero históricamente menos precisos en objetos pequeños. Con FPN, Focal Loss y arquitecturas anchor-free modernas, esta brecha de precisión se ha cerrado enormemente, haciendo a YOLO y RetinaNet la elección estándar para producción.

from transformers import (
    DetrImageProcessor,
    DetrForObjectDetection
)
import torch
from PIL import Image
import requests

# Cargar modelo preentrenado COCO
processor = DetrImageProcessor.from_pretrained(
    "facebook/detr-resnet-50")
model = DetrForObjectDetection.from_pretrained(
    "facebook/detr-resnet-50")

# Inferencia
image = Image.open("imagen.jpg")
inputs = processor(
    images=image, return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs)

# Post-procesar (filtrar por umbral)
target_sizes = torch.tensor([image.size[::-1]])
results = processor.post_process_object_detection(
    outputs,
    target_sizes=target_sizes,
    threshold=0.9
)[0]

for score, label, box in zip(
    results["scores"],
    results["labels"],
    results["boxes"]
):
    box = [round(i, 2) for i in box.tolist()]
    print(f"{model.config.id2label[label.item()]}"
          f" {score:.2f} → {box}")

¿Qué hizo revolucionario a DETR?
DETR fue el primer detector completamente end-to-end sin necesidad de anclas, NMS ni propuestas de región. Los object queries son vectores aprendibles que compiten mediante atención cruzada por las distintas entidades en la imagen. El Hungarian matching durante entrenamiento asegura asignación óptima sin duplicados. Sus variantes posteriores (Deformable DETR, DN-DETR, RT-DETR) resolvieron la lenta convergencia y permitieron detección en tiempo real con la misma filosofía sin anclas.
